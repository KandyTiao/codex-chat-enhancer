## 少翻目录，先看该看的

| 原来的麻烦 | 装上后怎么解决 |
| --- | --- |
| 回复蓝点埋在其他项目里 | **未读回复**集中在顶部，折叠项目中的蓝点也能看到 |
| Codex 等你回答或审批，你没注意 | **需要你处理**集中展示待答问题、审批和错误 |
| 任务跑了半天，不知道运行多久 | **运行超长时间项目**满 30 分钟后出现，实时累计时长 |

未读直接跟随 Codex 官方蓝点，与运行状态独立。点击打开同一原聊天后，跟随官方已读回传退出，不会批量替你标记已读。

计时超过 1 小时继续累计，本轮结束退出，新轮重新计时。实际起点不可读时明确显示“已观察运行”。时长帮助你决定是否检查任务，不等于判定卡死，也不会自动重启、声光报警或推送提醒。

## 三步开始

1. 准备 **Node.js 24+**、官方 Windows Codex，以及可用的本机调试连接（默认 39222 端口）。只想试界面，可先运行指南中的“仅示例”模式。
2. 下载 ZIP 并解压到可写文件夹，双击 **启动开发预览.cmd**。
3. 打开带侧栏的 Codex，按指南核对是否原生接入成功；示例网页能打开，不代表真实接入成功。

停止时双击 **停止开发预览.cmd**。当前是脚本使用包，不是独立 EXE 安装器；不设置登录自启动，不替你重启 Codex。[详细安装、启动与排查](docs/INSTALL.zh-CN.md)。

## 本机运行与验证范围

不额外发起模型请求，不上传作者服务器；只读取本机侧栏身份和状态，保存自己的偏好，不复制聊天正文或登录资料。官方更新可能改变内部接口，需要重新验证。已通过 88 项单元、65 项预览、17 项原生检查；远程／ChatGPT 完整行为和 Mac 实机兼容性仍待验证。
