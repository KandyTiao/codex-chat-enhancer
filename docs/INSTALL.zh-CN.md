# Codex Chat Enhancer｜Codex 聊天增强软件 · 新手使用指南

[English](INSTALL.md) · [图文介绍](../README.zh-CN.md)

## 先确认能不能运行

已验证环境：Windows Codex 26.1002.7124，需要 Node.js 24+。在终端运行 node --version 可查看版本。

真实接入还需要官方 Codex 已开启本机调试连接。浏览器打开 http://127.0.0.1:39222/json/list，应能看到调试页面列表。这个端口只保留在本机，不要对外网开放。网页示例能运行，不代表已有调试连接。

已经使用《Codex搭子》：若当前 Codex 需要增强重开，先等任务结束，再正常退出并使用搭子的桌面入口打开。聊天增强软件随后连接该窗口；它不会替你重启 Codex。

独立使用：在空闲 Codex 正常退出后，用你已经确认的官方桌面 GUI 路径启动，并传入 --remote-debugging-address=127.0.0.1 --remote-debugging-port=39222。应使用真正的 Codex.exe 桌面程序，不能用命令行 codex 代替。Store 版本路径会变化，当前包不含独立 Codex 启动器；无法建立连接时，可先用“仅示例”模式试界面。

## 下载、解压、启动

1. 下载 codex-chat-enhancer-v0.1.3.zip，解压到你有写入权限的文件夹。打开后应直接看到 package.json、src、web、scripts 和两个 .cmd 入口。
2. 双击 启动开发预览.cmd，打开 http://127.0.0.1:19767/ 示例页，同时尝试接入现有 Codex。
3. 打开 Codex 侧栏，顶部应出现三栏。再打开 http://127.0.0.1:19767/api/health：version 应为 0.1.3，native.available 应为 true，native.connected 应大于 0。这才是原生接入的核对。
4. 点击条目回到同一原聊天；查看后跟随官方已读状态退出。右键任一模块可选主题，点击标题可折叠。

启动脚本优先使用 PATH 中的 node.exe，也会尝试已有 Codex 的 Node 运行时；找不到时请安装 Node.js 24+。不需要 npm 安装依赖。当前没有正式安装器，也不设置登录自启动。

## 只想试一下界面

在解压后的文件夹打开终端，运行：

    node src/server.cjs --preview-only

再打开 http://127.0.0.1:19767/。全部聊天与状态操作均为虚构示例，此模式不会连接 Codex。若端口已占用，先正常停止对应实例或另选端口，不结束其他程序。

## 停止和移除

双击 停止开发预览.cmd，或在该文件夹运行 node scripts/control.cjs。只停止本软件并移除它的界面和计时器，不结束 Codex 或搭子。确认停止后即可删除解压文件夹；需要保留偏好时，先备份 data/preferences.json。

## 设置与常见问题

需要修改端口时，将 config.example.json 复制成 config.json，仅调整支持的 port、cdpPort 等配置。默认服务端口 19767，调试端口 39222；19766 留给搭子，不能在这里使用。配置调整后只重启本软件，不修改程序文件。

示例页能打开但真实侧栏没有模块：先检查调试页面列表，再看健康接口。如果调试连接不存在，只能试示例；若官方升级后内部接口变了，需要等待适配。缺少可靠状态时显示不可用或未知，不从停止、旧目录或更新时间猜测。

任务运行很久：本软件只展示时长，让你自行检查，并不判断卡死或自动重启。Windows 拦截脚本时，应检查文件来源并遵守单位的执行策略；当前包不是签名 EXE 安装器。
